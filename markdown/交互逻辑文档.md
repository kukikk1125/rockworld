# RockWorld 各模块与按钮交互逻辑文档

## 1. 文档说明

本文档按当前代码状态整理所有主要模块、按钮、弹层和跳转行为，重点说明：

- 按钮在什么位置
- 点击后发生什么
- 是否修改本地数据
- 是否弹窗
- 是否跳转页面

---

## 2. 全局交互框架 ASCII 图

```text
用户操作
   |
   +--> 一级导航切换
   |
   +--> 首页创建 / 继续任务
   |
   +--> 任务记录页高频录入
   |      |
   |      +--> 污染 +1
   |      +--> 原色 +1
   |      +--> 确认异色
   |      +--> 撤销上一步
   |      +--> 记录意外异色
   |
   +--> 图鉴进入精灵详情
   |
   +--> 精灵详情快捷记录
          |
          +--> 直接写入唯一进行中任务
          +--> 或选择归属任务
```

## 3. 一级导航逻辑

位置：所有页面底部固定导航。

按钮：

- 首页
- 记录
- 图鉴
- 我的

交互逻辑：

- 点击后直接跳转对应一级路由
- 当前路由对应项高亮
- 不修改本地数据
- 不触发弹窗

---

## 4. 首页 `/`

### 4.1 进行中任务卡片

位置：首页“进行中任务”列表。

点击区域：

- 整张任务卡片

交互逻辑：

- 调用 `setCurrentTask(task.id)`
- 跳转到 `/tasks/view?taskId=...`
- 不修改任务内容

### 4.2 首页任务卡片的“删除”

位置：任务卡片右上角。

交互逻辑：

- 先阻止事件冒泡，避免触发整卡跳转
- 打开删除确认弹窗
- 点击“取消”：关闭弹窗，不改数据
- 点击“删除任务”：调用 `deleteTask(task.id)`

当前删除语义：

- 只删除任务过程
- 不删除已经存档的异色成果

### 4.3 3×3 混抓方案卡“开始记录 / 继续记录”

位置：首页“选择抓取方案”区域。

交互逻辑：

- 如果该方案已有任务：直接打开已有任务
- 如果还没有任务：
  - `createTaskFromPlan(plan)`
  - `saveTask(task)`
  - 弹出提示弹窗
  - 跳转到任务记录页

### 4.4 定向果实法卡片

位置：首页方案列表顶部。

交互逻辑：

- 不直接建任务
- 点击后打开“选择定向精灵”弹层

### 4.5 定向精灵选择弹层

按钮与交互：

- `关闭`
  - 关闭弹层
  - 不改数据
- 某个精灵头像按钮
  - 先调用 `buildDirectedPlan(spirit)`
  - 若已有同 `planId` 任务：直接进入已有任务
  - 若无任务：
    - 创建任务
    - 保存任务
    - 关闭弹层
    - 提示“已创建任务，开始记录后它会出现在进行中任务里”
    - 跳转任务记录页

## 5. 记录页 `/history`

### 5.1 顶部 Tab

按钮：

- `任务列表`
- `已存档异色`

交互逻辑：

- 仅切换本地状态 `tab`
- 不跳路由
- 不修改持久化数据

### 5.2 任务列表中的任务卡片

交互逻辑：

- 点击整卡
- 设置当前任务
- 跳转到任务记录页

### 5.3 记录页任务卡片“删除”

交互逻辑与首页一致：

- 打开确认弹窗
- 确认后删除任务
- 已存档异色成果保留

### 5.4 已存档异色卡片

交互逻辑分两类：

- `clickable = true`
  - 整卡可点击
  - 打开历史快照抽屉
- `clickable = false`
  - 仅展示信息
  - 不能展开

当前对应关系：

- 方案内异色：可点开
- 意外异色：只展示，不可点开

### 5.5 历史快照抽屉

按钮：

- `关闭`

交互逻辑：

- 关闭抽屉
- 不修改数据

展示内容：

- 精灵
- 方案
- 获得时间
- 当时污染记录
- 当时原色记录

## 6. 图鉴页 `/pets`

### 6.1 搜索框

交互逻辑：

- 输入时实时更新 `keyword`
- 立即过滤精灵列表
- 不写入持久化数据

过滤规则：

- 名称包含关键词
- 结果按“已拥有优先” + “中文名称排序”

### 6.2 精灵卡片

交互逻辑：

- 点击整卡跳转到 `/spirits/view?spiritId=...`
- 不直接修改数据

页面反馈：

- 如果全局已有异色记录，右上角显示异色次数角标
- 已拥有精灵使用高亮背景和边框

## 7. 我的 `/settings`

内容：

- 总异色数
- 已拥有种类
- 最近获得异色

交互逻辑：

- 当前没有修改型按钮
- 不修改本地数据
- 不弹窗

## 8. 任务记录页 `/tasks/view`

这是当前软件最核心的高频操作页。

### 8.1 页面初始化逻辑

进入页面后：

- 从 URL 查询参数读取 `taskId`
- 调用 `getTaskById(taskId)`
- 找到任务后：
  - 加载任务
  - 加载精灵库
  - 设置为当前任务
- 若没找到任务：
  - 展示“没有找到对应任务”
  - 提供返回首页 / 返回记录页按钮

### 8.2 “记录意外异色”

位置：精灵记录区标题右侧。

交互逻辑：

- 打开 `SpiritPickerDialog`
- 用于记录本任务中方案外遇到的异色

### 8.3 意外异色弹层

按钮与行为：

- `关闭`
  - 关闭弹层
  - 不改数据
- 搜索输入
  - 实时过滤精灵列表
- 点击现有精灵
  - `createUnexpectedShinyArchiveRecord(task, spirit)`
  - `saveShinyArchiveRecord(...)`
  - 任务只更新 `hasStarted` 和 `updatedAt`
  - 不把该精灵加入当前任务卡片区
  - 关闭弹层
  - 底部 toast 提示
- `新增精灵 “xxx”`
  - 先 `upsertSpirit(...)`
  - 再按“意外异色”逻辑存档
  - 新精灵进入全局精灵库

### 8.4 精灵记录卡总体结构 ASCII 图

```text
+--------------------------------------------------------------------------------+
| 精灵头像 + 名称 + 全局异色角标             [撤销上一步]                         |
| Badge: 记录中 / 保底就绪 / 本轮异色                                              |
|                                                                                |
| 80 格保底进度条                                                                 |
| [污染格][污染格][原色格][空格] ...                                               |
|                                                                                |
| 统计区                                                                          |
| [污染数量] [原色数量] [本轮异色]                                                 |
|                                                                                |
| 操作区                                                                          |
| [污染 +1] [原色 +1]                                                             |
| [确认异色]                                                                      |
+--------------------------------------------------------------------------------+
```

### 8.5 `污染 +1`

交互逻辑：

- 调用 `addPollutionCount(task, spiritId, 1)`
- 在 `progressMarks` 追加一个 `pollution`
- 更新 `pollutionCount`
- 更新 `lastAction`
- 设置 `hasStarted = true`
- 更新时间 `updatedAt`
- 保存任务

页面反馈：

- 新格子高亮闪烁
- 提示“已记录：污染 +1”

### 8.6 `原色 +1`

交互逻辑：

- 调用 `addNormalCount(task, spiritId, 1)`
- 在 `progressMarks` 追加一个 `normal`
- 更新 `normalCount`
- 更新 `lastAction`
- 保存任务

页面反馈：

- 新格子高亮闪烁
- 提示“已记录：原色 +1”

### 8.7 `确认异色`

交互逻辑：

- 调用 `archiveTargetShiny(task, spirit)`
- 生成方案内异色存档记录
- `saveShinyArchiveRecord(archiveRecord)`
- 当前精灵卡片的以下字段清零：
  - `pollutionCount`
  - `normalCount`
  - `currentShinyCount`
  - `progressMarks`
- `lastAction` 记录为一次可撤销的 `shiny`
- 保存任务

结果语义：

- 当前轮次正式存档
- 自动进入下一轮记录
- 卡片不会消失

页面反馈：

- 卡片提示“已确认异色，当前轮次已存档并自动进入下一轮”
- toast：“异色已存档”

### 8.8 `撤销上一步`

交互逻辑：

- 若当前卡存在 `lastAction`，则可点击
- 调用 `undoSpiritLastAction(task, spiritId)`
- 恢复上一状态

恢复规则：

- 如果上一步是污染：恢复原污染数量和进度格
- 如果上一步是原色：恢复原原色数量和进度格
- 如果上一步是异色：
  - 恢复存档前的污染 / 原色 / 进度格
  - 删除对应异色存档记录

页面反馈：

- toast：“已撤销上一步”

### 8.9 toast 提示

当前会出现 toast 的场景：

- 方案内异色存档成功
- 方案外异色存档成功
- 撤销成功

特点：

- 自动消失
- 不阻塞继续操作

## 9. 精灵详情页 `/spirits/view`

### 9.1 快捷记录按钮组

按钮：

- `污染 +1`
- `原色 +1`
- `记录异色`

### 9.2 快捷记录分流规则

点击任一快捷记录按钮后，系统先判断进行中任务数量：

- `0 个`
  - 打开提示弹窗
  - 提示先从首页创建任务
- `1 个`
  - 直接写入这个任务
- `多个`
  - 打开任务选择弹层
  - 由用户选择归属任务

### 9.3 多任务选择弹层

按钮：

- `关闭`
- 某一个任务卡

交互逻辑：

- `关闭`：取消本次快捷记录
- 选中任务：
  - 执行对应快捷记录动作
  - 关闭弹层
  - 刷新精灵详情统计

### 9.4 精灵详情里的“回到任务页记录”

位置：抓取方案列表中每张方案卡底部。

交互逻辑：

- 若该方案已有任务：
  - 设置当前任务
  - 直接跳转任务记录页
- 若没有任务：
  - 基于方案创建任务
  - 保存任务
  - 设置当前任务
  - 跳转任务记录页

定向方案特殊规则：

- 若卡片是定向方案，会先基于当前精灵生成专属定向计划

## 11. 当前交互设计结论

当前版本的核心交互原则是：

- 首页负责“创建和继续”
- 任务记录页负责“高频录入”
- 精灵详情页负责“跨任务汇总和快捷补录”
- 记录页负责“回看和删除任务”
- 图鉴页负责“检索和进入精灵维度”

其中最关键的业务语义有两条：

- 方案内异色：存档后自动进入下一轮
- 方案外异色：只进入存档，不污染当前任务卡片区
