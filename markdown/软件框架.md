# RockWorld 软件框架文档

## 1. 文档说明

本文档基于当前代码状态整理，覆盖软件页面框架、路由结构、核心组件分层、数据流和部署结构。

当前项目定位：

- 前端框架：Next.js 15 + React 19 + TypeScript
- UI 方案：Tailwind CSS + 自定义基础组件
- 数据存储：浏览器 `localStorage`
- 部署模式：生产环境静态导出，适配 GitHub Pages
- 当前产品主题：RockWorld 异色精灵抓取记录与图鉴管理

---

## 2. 一级页面框架

当前软件以 4 个一级页面为主，底部导航固定存在：

- 首页 `/`
- 记录 `/history`
- 图鉴 `/pets`
- 我的 `/settings`

此外还有 2 个静态详情页：

- 任务记录页 `/tasks/view?taskId=...`
- 精灵详情页 `/spirits/view?spiritId=...`

## 4. 路由与页面职责

### 4.1 首页 `/`

职责：

- 展示进行中任务
- 展示抓取方案入口
- 创建新任务
- 继续已有任务
- 删除任务
- 打开定向精灵选择弹层

页面结构：

```text
首页
├─ 任务启动总览
│  ├─ 已拥有异色统计
│  └─ 进行中任务列表
│     └─ 任务卡片
├─ 选择抓取方案
│  ├─ 定向果实法入口卡
│  └─ 3×3 混抓方案卡列表
├─ 定向精灵选择弹层
└─ 删除确认 / 提示弹窗
```

### 4.2 记录 `/history`

职责：

- 查看任务列表
- 查看异色存档列表
- 删除任务
- 查看方案内异色历史快照

页面结构：

```text
记录页
├─ 顶部 Tab
│  ├─ 任务列表
│  └─ 已存档异色
├─ 任务列表面板
│  └─ 任务卡片
├─ 存档列表面板
│  └─ 异色存档卡片
├─ 历史快照抽屉
└─ 删除确认弹窗
```

### 4.3 图鉴 `/pets`

职责：

- 展示全量精灵
- 根据是否已拥有异色高亮
- 搜索精灵
- 跳转精灵详情

页面结构：

```text
图鉴页
├─ 图鉴总览卡
│  ├─ 已拥有统计
│  └─ 搜索框
└─ 精灵网格
   └─ 精灵卡片
```

### 4.4 我的 `/settings`

职责：

- 展示总异色数
- 展示已拥有种类数
- 展示最近获得异色

页面结构：

```text
我的
├─ 数据总览卡
│  ├─ 总异色数
│  └─ 已拥有种类

```

### 4.5 任务记录页 `/tasks/view`

职责：

- 承载核心记录流程
- 按精灵卡片记录污染、原色、异色
- 撤销上一步
- 记录意外异色

页面结构：

```text
任务记录页
├─ 任务摘要卡
│  ├─ 方案模式
│  ├─ 任务名称
│  ├─ 果实配方
│  └─ 目标精灵头像条
├─ 精灵记录区
│  ├─ 记录意外异色按钮
│  └─ 精灵记录卡列表
│     └─ 单卡包含：
│        ├─ 精灵头像与异色角标
│        ├─ 保底进度 80 格
│        ├─ 污染 / 原色 / 本轮异色统计
│        ├─ 污染 +1
│        ├─ 原色 +1
│        ├─ 确认异色
│        └─ 撤销上一步
├─ 底部 toast
└─ 精灵选择弹层
```

职责：

```text

├─ 精灵总览卡
│  ├─ 总异色
│  ├─ 最近获得时间
│  └─ 快捷记录按钮组

│  └─ 任务统计卡列表

```

## 6. 组件分层

### 6.1 壳层

- `layout.tsx`：唯一允许输出 `<html>` 和 `<body>` 的根布局
- `page-shell.tsx`：统一页面容器、标题区、底部留白、底部导航
- `bottom-nav.tsx`：一级导航切换

### 6.2 页面层

- `src/app/*`：负责路由入口和页面级组装
- `tasks/view/page.tsx` 与 `spirits/view/page.tsx` 仅负责挂载 `Suspense + Client Component`

### 6.3 业务交互层

- `plan-record-client.tsx`：任务记录核心逻辑
- `spirit-detail-client.tsx`：精灵维度汇总与快捷记录
- `spirit-picker-dialog.tsx`：精灵选择 / 新建精灵
- `task-select-dialog.tsx`：多任务归属选择

### 6.4 数据与规则层

- `task-factory.ts`：方案与任务对象生成
- `calculations.ts`：统计、加减、归档、撤销
- `storage.ts`：本地持久化与历史数据迁移
- `types/index.ts`：统一数据模型

## 9. 当前部署与路由策略

生产环境 `next.config.ts` 当前配置：

- `output: "export"`
- `basePath: "/rockworld"`
- `trailingSlash: true`
- `images.unoptimized: true`

因此当前部署策略是：

- 首页和一级页使用静态导出目录路由
- 任务详情和精灵详情不走运行时动态文件路由
- 详情页通过查询参数读取 `taskId` 与 `spiritId`

正确形式：

- `/rockworld/tasks/view/?taskId=...`
- `/rockworld/spirits/view/?spiritId=...`

不再作为线上主入口的形式：

- `/rockworld/tasks/[id]`
- `/rockworld/spirits/[id]`

## 10. 当前软件框架结论

当前版本的软件框架已经稳定为：

- 一级导航固定的移动端单页式体验
- 任务记录页承担高频录入
- 精灵详情页承担全局汇总与回流记录
- 图鉴页承担全量浏览与检索
- 历史页承担任务与存档回看
- 数据层统一走 `localStorage + 迁移兜底`
- 部署层统一适配 GitHub Pages 静态导出

这四条主链路已经足够支撑当前软件继续迭代：

- 新建任务
- 过程记录
- 异色存档
- 图鉴沉淀
